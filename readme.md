<summary><b>English</b></summary>

This has some reference value for certain ArtDink games, such as `asb` scripts, `pidx` DAT packages, `fsts` sub-packages, and so on.
It currently also supports file processing for *Galaxy Angel 1*. Since the AGI format has partially changed between the two games, do **not** use `agi.xml` for *Galaxy Angel 2* (if this file is generated during resource extraction, please delete it). For *Galaxy Angel 1*, however, this file is required, so do not delete it.

**Note:** This is a localization tool for **Galaxy Angel 2**. If you only want to extract resource files, please use the more convenient [VerViewer](https://github.com/icey9527/Verviewer).

Most files that need modification for GA2 are in: **ADV.DAT**, **ALL.DAT**, **SLG.DAT**

To edit PSS videos, also check: **STRM_R.DAT**, **STRM_R2.DAT**

For editing script files, please use the tools in python_tools.
